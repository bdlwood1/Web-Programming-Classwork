LEGO Star Wars Character Dictionary

About This Website

I wanted to create a LEGO Star Wars Character Dictionary because I wanted to make a website based on something I already enjoy. And so naturally, that led me to LEGO Star Wars. I have enjoyed LEGO Star Wars content since I was a kid, so I have a lot of background knowledge about the topic, which would make it easier for me to create a website about it. I also wanted to create a website that would be useful to other people who enjoy LEGO Star Wars. LEGO Star Wars has many different characters, sets, and minifigures, so I thought it would be interesting to create a website that organizes information about some of those characters and even provides links to purchase them.

I was motivated to create this website because I have always enjoyed LEGO Star Wars. There are many different LEGO versions of characters like Luke Skywalker, Darth Vader, and Ahsoka Tano. Some of them have the tiniest changes, like an extra arm print, different torso printing, or a slightly different color in a certain area, which I think is really cool. I thought a character dictionary would be a simple way for someone to learn more about the characters and even give them a way to purchase them.

Another reason I created this site was to practice building webpages with HTML and CSS. Creating this website gives me a chance to work with page layouts, links, colors, fonts, and different types of content. In the future, I would like to add more characters and continue improving the website. I also plan to add links under each character that take users to BrickLink if they want to buy that specific LEGO minifigure. I would also like to include links to the LEGO Store for sets that include that character, as long as those sets have not been retired.
